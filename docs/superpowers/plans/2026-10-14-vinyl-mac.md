# Vinyl pour Mac — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire une app macOS (Go + Wails v3 + Tailwind v4) qui recrée fidèlement MD Vinyl : platine vinyle animée qui pilote Apple Music et Spotify, widget flottant, bibliothèque, page artiste, personnalisation et carte de partage.

**Architecture:** Un backend Go interroge Musique et Spotify via `osascript` toutes les 500 ms (`internal/player`), choisit la source active (`watcher`) et émet un événement `nowplaying` vers deux fenêtres Wails (widget flottant transparent + fenêtre principale). Le catalogue (bibliothèque, artiste) passe par AppleScript + API iTunes Search (Apple Music) et Spotify Web API (OAuth PKCE, jeton dans le Trousseau). Le frontend en TypeScript vanilla + Tailwind v4 rend la platine en DOM/CSS, avec une logique pure (bras, rotation, textures) testée sous Vitest.

**Tech Stack:** Go 1.26, Wails v3.0.0-beta.29 (`github.com/wailsapp/wails/v3`), `github.com/zalando/go-keyring`, Vite 8, TypeScript, Tailwind CSS v4 (`@tailwindcss/vite`), Vitest, `@wailsio/runtime`.

**Spec:** `docs/superpowers/specs/2026-10-14-vinyl-mac-design.md`

## Global Constraints

- Go 1.26 ; module Go nommé `vinyl`.
- Wails **v3.0.0-beta.29** exactement (CLI `wails3` à la même version).
- Frontend : TypeScript vanilla (pas de framework), Tailwind CSS **v4**, Vite, Vitest.
- macOS uniquement (darwin/arm64) ; build local, pas de signature ni notarisation.
- Ne jamais lancer Musique ou Spotify : toujours tester `application id "…" is running` avant un `tell`.
- Aucune valeur utilisateur interpolée dans un AppleScript : tout passe par `argv` (`on run argv`).
- Bundle IDs : Musique = `com.apple.Music`, Spotify = `com.spotify.client`.
- Rotation : 33⅓ tours/min (1 800 ms par tour) ; accélération 600 ms ; décélération 1 200 ms.
- Bras : repos 4°, début du morceau 18°, fin du morceau 34°, seuil de levée 12°.
- Sondage 500 ms ; ré-émission forcée toutes les 2 s ; timeout AppleScript 2 s ; timeout HTTP 10 s.
- Réglages : `~/Library/Application Support/Vinyl/settings.json` ; cache pochettes : `~/Library/Caches/Vinyl/artwork/`.
- Jetons Spotify : Trousseau, service `Vinyl.Spotify` ; jamais sur disque en clair.
- Redirect URI Spotify : `http://127.0.0.1:43821/callback` (port fixe, à déclarer dans le dashboard Spotify).
- Widget : 220×220, sans bordure, transparent, toujours au premier plan. Fenêtre principale : 1100×720.
- Interface en français, thème sombre uniquement.
- Ne reprendre aucun nom, icône, image ou texture de MD Vinyl ; le son de craquement est synthétisé (WebAudio), pas un fichier.
- Commits : messages en français au format `type: description`, terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Locale française** : AppleScript renvoie les réels avec une virgule (`213,5`) sur un Mac en français — les durées/positions doivent être lues correctement (test dans Task 2).
2. **Titres avec guillemets, accents, emoji ou séparateurs** (`Don't Stop "Live"`, `Beyoncé`) — aucun plantage ni injection AppleScript (tests Task 2 et Task 3 : passage par argv).
3. **Morceau sans durée** (radio Apple Music, flux, pub Spotify : durée `missing value` ou 0) — le bras ne doit pas produire `NaN` et reste au début du sillon (tests Task 3 et Task 8).
4. **Lecteur quitté pendant le sondage / permission refusée** (erreurs −600 / −1743) — la platine passe à l'état « Lance Musique ou Spotify » ou à l'écran d'aide, sans boucle d'erreurs (tests Task 5).
5. **Fichier de réglages corrompu ou d'une ancienne version** — l'app démarre avec les valeurs par défaut au lieu de planter (test Task 6).

```go
// Package player pilote les lecteurs de musique macOS (Musique, Spotify) via AppleScript.
package player

import (
	"context"
	"errors"
	"time"
)

type State string

const (
	StatePlaying State = "playing"
	StatePaused  State = "paused"
	StateStopped State = "stopped"
)

var (
	ErrNotRunning    = errors.New("lecteur non lancé")
	ErrNotAuthorized = errors.New("automatisation non autorisée")
)

type NowPlaying struct {
	Source     string `json:"source"`
	TrackID    string `json:"trackId"`
	Title      string `json:"title"`
	Artist     string `json:"artist"`
	Album      string `json:"album"`
	DurationMs int64  `json:"durationMs"`
	PositionMs int64  `json:"positionMs"`
	State      State  `json:"state"`
	ArtworkURL string `json:"artworkUrl"`
}

type Player interface {
	Name() string
	NowPlaying(ctx context.Context) (NowPlaying, error)
	PlayPause(ctx context.Context) error
	Next(ctx context.Context) error
	Previous(ctx context.Context) error
	Seek(ctx context.Context, pos time.Duration) error
	PlayItem(ctx context.Context, id string) error
}

func parseState(s string) State {
	switch s {
	case "playing":
		return StatePlaying
	case "paused":
		return StatePaused
	default:
		return StateStopped
	}
}
```

`internal/player/osascript.go` :

```go
package player

import (
	"bytes"
	"context"
	"fmt"
	"os/exec"
	"strconv"
	"strings"
)

// Sep sépare les champs renvoyés par nos scripts (ASCII Unit Separator).
const Sep = "\x1f"

type Runner interface {
	Run(ctx context.Context, script string, args ...string) (string, error)
}

// OSAScript exécute un AppleScript via /usr/bin/osascript.
// Les valeurs utilisateur passent toujours par argv, jamais dans le texte du script.
type OSAScript struct{}

func (OSAScript) Run(ctx context.Context, script string, args ...string) (string, error) {
	cmd := exec.CommandContext(ctx, "/usr/bin/osascript", append([]string{"-e", script}, args...)...)
	var stdout, stderr bytes.Buffer
	cmd.Stdout, cmd.Stderr = &stdout, &stderr
	if err := cmd.Run(); err != nil {
		if ctx.Err() != nil {
			return "", ctx.Err()
		}
		return "", classifyError(stderr.String())
	}
	return strings.TrimRight(stdout.String(), "\n"), nil
}

func classifyError(stderr string) error {
	switch {
	case strings.Contains(stderr, "(-1743)"):
		return ErrNotAuthorized
	case strings.Contains(stderr, "(-600)"):
		return ErrNotRunning
	default:
		return fmt.Errorf("osascript: %s", strings.TrimSpace(stderr))
	}
}

func parseFloat(s string) (float64, bool) {
	s = strings.ReplaceAll(strings.TrimSpace(s), ",", ".")
	f, err := strconv.ParseFloat(s, 64)
	if err != nil || f < 0 {
		return 0, false
	}
	return f, true
}

// parseSeconds convertit des secondes AppleScript ("213,5" ou "213.5") en millisecondes.
func parseSeconds(s string) int64 {
	f, ok := parseFloat(s)
	if !ok {
		return 0
	}
	return int64(f*1000 + 0.5)
}

// parseMillis lit une valeur déjà en millisecondes.
func parseMillis(s string) int64 {
	f, ok := parseFloat(s)
	if !ok {
		return 0
	}
	return int64(f + 0.5)
}
```

```go
package player

import (
	"context"
	"errors"
	"sync"
	"time"
)

const (
	resyncEvery = 2 * time.Second
	scriptLimit = 2 * time.Second
)

type Snapshot struct {
	NowPlaying NowPlaying `json:"nowPlaying"`
	Problem    string     `json:"problem"`
	ProblemApp string     `json:"problemApp"`
}

type Watcher struct {
	players []Player
	mode    func() string
	emit    func(Snapshot)
	now     func() time.Time
	wake    chan struct{}

	mu           sync.Mutex
	active       string
	last         Snapshot
	lastEmit     time.Time
	emittedOnce  bool
	prevState    map[string]State
	playingSince map[string]time.Time
}

func NewWatcher(players []Player, mode func() string, emit func(Snapshot), now func() time.Time) *Watcher {
	return &Watcher{
		players: players, mode: mode, emit: emit, now: now,
		wake:         make(chan struct{}, 1),
		prevState:    map[string]State{},
		playingSince: map[string]time.Time{},
	}
}

func (w *Watcher) Player(name string) Player {
	for _, p := range w.players {
		if p.Name() == name {
			return p
		}
	}
	return nil
}

func (w *Watcher) Active() Player {
	w.mu.Lock()
	defer w.mu.Unlock()
	if w.active == "" {
		return nil
	}
	return w.Player(w.active)
}

func (w *Watcher) Current() Snapshot {
	w.mu.Lock()
	defer w.mu.Unlock()
	return w.last
}

func (w *Watcher) Wake() {
	select {
	case w.wake <- struct{}{}:
	default:
	}
}

func (w *Watcher) Run(ctx context.Context, interval time.Duration) {
	t := time.NewTicker(interval)
	defer t.Stop()
	for {
		w.Tick(ctx)
		select {
		case <-ctx.Done():
			return
		case <-t.C:
		case <-w.wake:
		}
	}
}

func (w *Watcher) Tick(ctx context.Context) {
	mode := w.mode()
	candidates := w.players
	if mode != "auto" {
		if p := w.Player(mode); p != nil {
			candidates = []Player{p}
		}
	}

	now := w.now()
	results := map[string]NowPlaying{}
	permissionApp := ""

	w.mu.Lock()
	active, last := w.active, w.last
	w.mu.Unlock()

	for _, p := range candidates {
		cctx, cancel := context.WithTimeout(ctx, scriptLimit)
		np, err := p.NowPlaying(cctx)
		cancel()
		name := p.Name()
		switch {
		case errors.Is(err, ErrNotRunning):
			delete(w.prevState, name)
			continue
		case errors.Is(err, ErrNotAuthorized):
			if permissionApp == "" {
				permissionApp = name
			}
			continue
		case err != nil:
			// Erreur passagère (timeout…) : on garde le dernier état connu de la source active.
			if name == active && last.Problem == "" {
				results[name] = last.NowPlaying
			}
			continue
		}
		results[name] = np
		if np.State == StatePlaying && w.prevState[name] != StatePlaying {
			w.playingSince[name] = now
		}
		w.prevState[name] = np.State
	}

	chosen := ""
	for _, p := range candidates {
		np, ok := results[p.Name()]
		if ok && np.State == StatePlaying && (chosen == "" || w.playingSince[p.Name()].After(w.playingSince[chosen])) {
			chosen = p.Name()
		}
	}
	if chosen == "" {
		if _, ok := results[active]; ok {
			chosen = active
		}
	}
	if chosen == "" {
		for _, p := range candidates {
			if _, ok := results[p.Name()]; ok {
				chosen = p.Name()
				break
			}
		}
	}

	var snap Snapshot
	switch {
	case chosen != "":
		snap.NowPlaying = results[chosen]
	case permissionApp != "":
		snap.Problem, snap.ProblemApp = "permission", permissionApp
	default:
		snap.Problem = "no-player"
	}

	w.mu.Lock()
	w.active = chosen
	changed := !w.emittedOnce || differs(w.last, snap)
	due := now.Sub(w.lastEmit) >= resyncEvery
	w.last = snap
	if changed || due {
		w.lastEmit = now
		w.emittedOnce = true
	}
	w.mu.Unlock()

	if changed || due {
		w.emit(snap)
	}
}

func differs(a, b Snapshot) bool {
	return a.Problem != b.Problem || a.ProblemApp != b.ProblemApp ||
		a.NowPlaying.Source != b.NowPlaying.Source || a.NowPlaying.TrackID != b.NowPlaying.TrackID ||
		a.NowPlaying.State != b.NowPlaying.State || a.NowPlaying.ArtworkURL != b.NowPlaying.ArtworkURL
}
```

```go
// Package settings gère les préférences de l'app dans un fichier JSON.
package settings

import (
	"encoding/json"
	"os"
	"path/filepath"
	"regexp"
	"sync"
)

type Settings struct {
	Source          string    `json:"source"`
	Texture         string    `json:"texture"`
	DiscColors      [2]string `json:"discColors"`
	Accent          string    `json:"accent"`
	Crackle         bool      `json:"crackle"`
	WidgetX         int       `json:"widgetX"`
	WidgetY         int       `json:"widgetY"`
	WidgetPlaced    bool      `json:"widgetPlaced"`
	SpotifyClientID string    `json:"spotifyClientId"`
}

func Defaults() Settings {
	return Settings{
		Source:     "auto",
		Texture:    "black",
		DiscColors: [2]string{"#ffb300", "#fff3d6"},
		Accent:     "#f5c542",
		Crackle:    true,
	}
}

var hexColor = regexp.MustCompile(`^#[0-9a-fA-F]{6}$`)

func oneOf(v string, allowed ...string) bool {
	for _, a := range allowed {
		if v == a {
			return true
		}
	}
	return false
}

func Normalize(v Settings) Settings {
	d := Defaults()
	if !oneOf(v.Source, "auto", "applemusic", "spotify") {
		v.Source = d.Source
	}
	if !oneOf(v.Texture, "black", "picture", "yolk", "split", "solid") {
		v.Texture = d.Texture
	}
	for i := range v.DiscColors {
		if !hexColor.MatchString(v.DiscColors[i]) {
			v.DiscColors[i] = d.DiscColors[i]
		}
	}
	if !hexColor.MatchString(v.Accent) {
		v.Accent = d.Accent
	}
	return v
}

type Store struct {
	path string
	mu   sync.RWMutex
	cur  Settings
}

func NewStore(path string) *Store { return &Store{path: path, cur: Defaults()} }

func DefaultPath() (string, error) {
	dir, err := os.UserConfigDir() // ~/Library/Application Support
	if err != nil {
		return "", err
	}
	return filepath.Join(dir, "Vinyl", "settings.json"), nil
}

// Load lit le fichier. Fichier absent ou illisible → valeurs par défaut, sans erreur.
func (s *Store) Load() error {
	v := Defaults()
	if data, err := os.ReadFile(s.path); err == nil {
		if json.Unmarshal(data, &v) != nil {
			v = Defaults()
		}
	}
	s.mu.Lock()
	s.cur = Normalize(v)
	s.mu.Unlock()
	return nil
}

func (s *Store) Get() Settings {
	s.mu.RLock()
	defer s.mu.RUnlock()
	return s.cur
}

func (s *Store) Save(v Settings) error {
	v = Normalize(v)
	data, err := json.MarshalIndent(v, "", "  ")
	if err != nil {
		return err
	}
	if err := os.MkdirAll(filepath.Dir(s.path), 0o755); err != nil {
		return err
	}
	tmp := s.path + ".tmp"
	if err := os.WriteFile(tmp, data, 0o644); err != nil {
		return err
	}
	if err := os.Rename(tmp, s.path); err != nil {
		return err
	}
	s.mu.Lock()
	s.cur = v
	s.mu.Unlock()
	return nil
}
```

```go
package app

import (
	"net/http"
	"os"
	"path/filepath"
	"strings"

	"github.com/wailsapp/wails/v3/pkg/application"
)

// ArtworkMiddleware sert les pochettes exportées depuis Musique sous /artwork/<fichier>.
func ArtworkMiddleware(dir string) application.Middleware {
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			name, ok := strings.CutPrefix(r.URL.Path, "/artwork/")
			if !ok {
				next.ServeHTTP(w, r)
				return
			}
			if name == "" || name != filepath.Base(name) || strings.Contains(name, "..") {
				http.NotFound(w, r)
				return
			}
			data, err := os.ReadFile(filepath.Join(dir, name))
			if err != nil {
				http.NotFound(w, r)
				return
			}
			w.Header().Set("Content-Type", http.DetectContentType(data))
			w.Header().Set("Cache-Control", "max-age=86400")
			w.Write(data)
		})
	}
}
```

```go
package app

import (

const callLimit = 3 * time.Second

type VinylService struct {
	store   *settings.Store
	watcher *player.Watcher
}

func New(store *settings.Store, watcher *player.Watcher) *VinylService {
	return &VinylService{store: store, watcher: watcher}
}

var errNoPlayer = errors.New("aucun lecteur actif")

func (s *VinylService) withActive(f func(ctx context.Context, p player.Player) error) error {
	p := s.watcher.Active()
	if p == nil {
		return errNoPlayer
	}
	ctx, cancel := context.WithTimeout(context.Background(), callLimit)
	defer cancel()
	err := f(ctx, p)
	s.watcher.Wake()
	return err
}

func (s *VinylService) GetSnapshot() player.Snapshot { return s.watcher.Current() }

func (s *VinylService) PlayPause() error {
	return s.withActive(func(ctx context.Context, p player.Player) error { return p.PlayPause(ctx) })
}

func (s *VinylService) Next() error {
	return s.withActive(func(ctx context.Context, p player.Player) error { return p.Next(ctx) })
}

func (s *VinylService) Previous() error {
	return s.withActive(func(ctx context.Context, p player.Player) error { return p.Previous(ctx) })
}

func (s *VinylService) SeekMs(ms int64) error {
	return s.withActive(func(ctx context.Context, p player.Player) error {
		return p.Seek(ctx, time.Duration(ms)*time.Millisecond)
	})
}

// PlayItem lance une playlist, un album ou un titre sur la source donnée ("applemusic" ou "spotify").
func (s *VinylService) PlayItem(source, id string) error {
	p := s.watcher.Player(source)
	if p == nil {
		return errors.New("source inconnue")
	}
	ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
	defer cancel()
	err := p.PlayItem(ctx, id)
	s.watcher.Wake()
	return err
}

func (s *VinylService) GetSettings() settings.Settings { return s.store.Get() }

func (s *VinylService) SaveSettings(v settings.Settings) error {
	if err := s.store.Save(v); err != nil {
		return err
	}
	application.Get().Event.Emit("settings", s.store.Get())
	s.watcher.Wake()
	return nil
}

func (s *VinylService) OpenMainWindow() {
	if w, ok := application.Get().Window.GetByName("main"); ok {
		w.Show()
		w.Focus()
	}
}

// OpenAutomationSettings ouvre Réglages Système > Confidentialité et sécurité > Automatisation.
func (s *VinylService) OpenAutomationSettings() error {
	return exec.Command("open", "x-apple.systempreferences:com.apple.preference.security?Privacy_Automation").Run()
}
```

```ts
// Angles du bras en degrés. 0° = bras vertical ; positif = rotation horaire, vers le disque.
export const ARM_REST = 4;
export const ARM_START = 18;
export const ARM_END = 34;
export const ARM_LIFT = 12;

const clamp = (v: number, lo: number, hi: number) => Math.min(hi, Math.max(lo, v));

export function angleForProgress(positionMs: number, durationMs: number): number {
  if (!(durationMs > 0) || !Number.isFinite(positionMs)) return ARM_START;
  const p = clamp(positionMs / durationMs, 0, 1);
  return ARM_START + (ARM_END - ARM_START) * p;
}

export function positionForAngle(angle: number, durationMs: number): number {
  if (!(durationMs > 0)) return 0;
  const p = (clamp(angle, ARM_START, ARM_END) - ARM_START) / (ARM_END - ARM_START);
  return Math.round(p * durationMs);
}

export type Release = { kind: "pause" } | { kind: "seek"; positionMs: number };

export function releaseAction(angle: number, durationMs: number): Release {
  if (angle < ARM_LIFT) return { kind: "pause" };
  return { kind: "seek", positionMs: positionForAngle(angle, durationMs) };
}

export function angleFromPointer(pivot: { x: number; y: number }, pointer: { x: number; y: number }): number {
  const dx = pointer.x - pivot.x;
  const dy = pointer.y - pivot.y;
  return (Math.atan2(-dx, dy) * 180) / Math.PI;
}
```

```ts
export function estimatePosition(positionMs: number, durationMs: number, playing: boolean, receivedAt: number, now: number): number {
  if (!playing) return positionMs;

  return durationMs > 0 ? Math.min(p, durationMs) : p;
```

```ts
let ctx: AudioContext | null = null;

// Court craquement de vinyle généré (bruit filtré + quelques « pops »), sans fichier audio.
export function playCrackle(): void {
  ctx ??= new AudioContext();
  const sr = ctx.sampleRate;
  const len = Math.floor(sr * 0.45);
  const buf = ctx.createBuffer(1, len, sr);
  const data = buf.getChannelData(0);
  for (let i = 0; i < len; i++) {
    const fade = 1 - i / len;
    let v = (Math.random() * 2 - 1) * 0.05 * fade;
    if (Math.random() < 0.0009) v += (Math.random() < 0.5 ? -1 : 1) * 0.6 * fade;
    data[i] = v;
  }
  const src = ctx.createBufferSource();
  src.buffer = buf;
  const filter = ctx.createBiquadFilter();
  filter.type = "bandpass";
  filter.frequency.value = 2500;
  filter.Q.value = 0.7;
  src.connect(filter).connect(ctx.destination);
  src.start();
}
```

```ts
import { api } from "../api";

import { estimatePosition } from "./clock";

import { Spinner } from "./spin";
import { discBackground, type Texture } from "./textures";

type Variant = "full" | "widget";

const TEMPLATE_FULL = `
  <div class="tt-plinth relative rounded-2xl" style="width:420px;height:320px;background:linear-gradient(135deg,#2b2b2b,#1a1a1a);box-shadow:0 20px 50px rgba(0,0,0,.6),inset 0 1px 0 rgba(255,255,255,.08)">

    </div>
  </div>`;

const TEMPLATE_WIDGET = `<div class="tt-disc relative rounded-full flex items-center justify-center" style="width:200px;height:200px;box-shadow:0 12px 30px rgba(0,0,0,.55)"></div>`;

  <div class="absolute inset-0 rounded-full pointer-events-none" style="background:repeating-radial-gradient(circle,rgba(0,0,0,.25) 0 1px,transparent 1px 3px)"></div>
  <div class="absolute inset-0 rounded-full pointer-events-none" style="background:conic-gradient(transparent 0 20%,rgba(255,255,255,.14) 25%,transparent 30% 70%,rgba(255,255,255,.14) 75%,transparent 80%)"></div>

export class Turntable {
  private disc: HTMLElement;
  private label: HTMLElement;
  private arm: HTMLElement | null;
  private spinner = new Spinner();
  private snap: Snapshot | null = null;
  private receivedAt = 0;
  private dragAngle: number | null = null;
  private appearance: Settings | null = null;
  private raf = 0;
  private last = performance.now();
  private armWasDown = false;

  constructor(root: HTMLElement, private opts: { variant: Variant }) {
    root.innerHTML = opts.variant === "full" ? TEMPLATE_FULL : TEMPLATE_WIDGET;
    this.disc = root.querySelector(".tt-disc")!;
    this.disc.innerHTML = DISC_INNER;
    this.label = root.querySelector(".tt-label")!;
    this.arm = root.querySelector(".tt-arm");
    this.label.addEventListener("click", () => api.PlayPause());
    if (this.arm) this.bindArm(this.arm);
    this.raf = requestAnimationFrame(this.frame);
  }

  update(s: Snapshot): void {
    const prevTrack = this.snap?.nowPlaying.trackId;
    this.snap = s;
    this.receivedAt = performance.now();
    if (s.nowPlaying.trackId !== prevTrack) this.paint();
  }

  setAppearance(s: Settings): void {
    this.appearance = s;
    this.paint();
  }

  destroy(): void { cancelAnimationFrame(this.raf); }

  private get playing(): boolean { return this.snap?.problem === "" && this.snap.nowPlaying.state === "playing"; }

  private paint(): void {
    const art = this.snap?.nowPlaying.artworkUrl ?? "";
    const tex = (this.appearance?.texture ?? "black") as Texture;
    const colors = this.appearance?.discColors ?? ["#ffb300", "#fff3d6"];
    this.disc.style.background = discBackground(tex, colors, art);
    this.label.style.backgroundImage = art ? `url("${art.replace(/["\\]/g, "\\$&")}")` : "";
    this.label.style.backgroundColor = art ? "" : "var(--accent)";
    this.label.style.visibility = tex === "picture" && art ? "hidden" : "visible";
  }

  private frame = (now: number) => {
    const dt = Math.min(100, now - this.last);
    this.last = now;
    this.disc.style.transform = `rotate(${this.spinner.step(dt, this.playing)}deg)`;
    if (this.arm) {
      let angle = ARM_REST;
      if (this.dragAngle !== null) angle = this.dragAngle;
      else if (this.playing && this.snap) {
        const np = this.snap.nowPlaying;
        angle = angleForProgress(estimatePosition(np.positionMs, np.durationMs, true, this.receivedAt, now), np.durationMs);
      }
      const down = angle >= 12;
      if (down && !this.armWasDown && this.dragAngle === null && this.appearance?.crackle) playCrackle();
      this.armWasDown = down;
      this.arm.style.transform = `rotate(${angle}deg)`;
      this.arm.style.transition = this.dragAngle === null ? "transform .6s ease" : "none";
    }
    this.raf = requestAnimationFrame(this.frame);
  };

  private bindArm(arm: HTMLElement): void {
    // Pivot = transform-origin (4px, 8px) du bras, placé à right:44px / top:26px dans le socle, largeur 8px.
    const pivot = () => {
      const plinth = arm.parentElement!.getBoundingClientRect();
      return { x: plinth.right - 44 - 8 + 4, y: plinth.top + 26 + 8 };
    };
    arm.addEventListener("pointerdown", (e) => {
      arm.setPointerCapture(e.pointerId);
      this.dragAngle = angleFromPointer(pivot(), { x: e.clientX, y: e.clientY });
    });
    arm.addEventListener("pointermove", (e) => {
      if (this.dragAngle === null) return;
      this.dragAngle = Math.max(ARM_REST, Math.min(40, angleFromPointer(pivot(), { x: e.clientX, y: e.clientY })));
    });
    arm.addEventListener("pointerup", async () => {
      if (this.dragAngle === null) return;
      const action = releaseAction(this.dragAngle, this.snap?.nowPlaying.durationMs ?? 0);
      this.dragAngle = null;
      if (action.kind === "pause") {
        if (this.playing) await api.PlayPause();
        return;
      }
      if (this.appearance?.crackle) playCrackle();
      await api.SeekMs(action.positionMs);
      if (!this.playing) await api.PlayPause();
    });
  }
}
```

```ts
export type Route = "platine" | "playlists" | "albums" | "likes" | "artistes" | "artiste" | "personnaliser" | "reglages";
const ROUTES: Route[] = ["platine", "playlists", "albums", "likes", "artistes", "artiste", "personnaliser", "reglages"];

export function parseRoute(hash: string): { route: Route; param: string } {
  const [, name = "", ...rest] = hash.replace(/^#/, "").split("/");
  const route = (ROUTES as string[]).includes(name) ? (name as Route) : "platine";
  const param = route === "platine" ? "" : decodeURIComponent(rest.join("/"));
  return { route, param };
}

export function go(route: Route, param = ""): void {
  location.hash = `#/${route}${param ? "/" + encodeURIComponent(param) : ""}`;
}
```

```go
// Package catalog fournit la bibliothèque et les pages artiste pour chaque source.
package catalog

import (
	"context"
	"errors"
)

const PageSize = 50

var ErrUnsupported = errors.New("non disponible pour cette source")

type Item struct {
	ID         string `json:"id"`
	Kind       string `json:"kind"`
	Title      string `json:"title"`
	Subtitle   string `json:"subtitle"`
	ArtworkURL string `json:"artworkUrl"`
	URL        string `json:"url"`
}

type Page struct {
	Items []Item `json:"items"`
	Next  int    `json:"next"`
}

type ArtistPage struct {
	Source    string `json:"source"`
	Name      string `json:"name"`
	ImageURL  string `json:"imageUrl"`
	URL       string `json:"url"`
	TopTracks []Item `json:"topTracks"`
	Albums    []Item `json:"albums"`
}

type Catalog interface {
	Library(ctx context.Context, kind string, offset int) (Page, error)
	Artist(ctx context.Context, name, trackID string) (ArtistPage, error)
}

func paginate(items []Item, offset int) Page {
	if offset < 0 || offset > len(items) {
		offset = len(items)
	}
	end := min(offset+PageSize, len(items))
	next := end
	if end >= len(items) {
		next = -1
	}
	return Page{Items: items[offset:end], Next: next}
}
```

```go
import (

type ITunes struct {
	BaseURL string
	HTTP    *http.Client
	Country string
}

func NewITunes() *ITunes {
	return &ITunes{BaseURL: "https://itunes.apple.com", HTTP: &http.Client{Timeout: 10 * time.Second}, Country: "FR"}
}

type itunesResult struct {
	WrapperType       string `json:"wrapperType"`
	ArtistID          int64  `json:"artistId"`
	ArtistName        string `json:"artistName"`
	ArtistLinkURL     string `json:"artistLinkUrl"`
	TrackID           int64  `json:"trackId"`
	TrackName         string `json:"trackName"`
	CollectionID      int64  `json:"collectionId"`
	CollectionName    string `json:"collectionName"`
	ReleaseDate       string `json:"releaseDate"`
	ArtworkURL100     string `json:"artworkUrl100"`
	TrackViewURL      string `json:"trackViewUrl"`
	CollectionViewURL string `json:"collectionViewUrl"`
}

func hd(u string) string { return strings.Replace(u, "100x100bb", "600x600bb", 1) }

func (c *ITunes) get(ctx context.Context, path string, q url.Values) ([]itunesResult, error) {
	if c.Country != "" {
		q.Set("country", c.Country)
	} else {
		q.Set("country", "FR")
	}
	req, err := http.NewRequestWithContext(ctx, "GET", c.BaseURL+path+"?"+q.Encode(), nil)
	if err != nil {
		return nil, err

	}

}

			}
```

```go
				continue
			}

			if !seen[key] {
				seen[key] = true
				items = append(items, Item{ID: "album:" + key, Kind: "album", Title: r[0], Subtitle: r[1]})
			}
		}
		sort.Slice(items, func(i, j int) bool { return strings.ToLower(items[i].Title) < strings.ToLower(items[j].Title) })
	case "artists":
		recs, err := m.records(ctx, artistsScript)
		if err != nil {
			return Page{}, err
		}
		seen := map[string]bool{}
		for _, r := range recs {
			name := strings.TrimSpace(r[0])
			if name != "" && !seen[name] {
				seen[name] = true
				items = append(items, Item{ID: name, Kind: "artist", Title: name})
			}
		}
		sort.Slice(items, func(i, j int) bool { return strings.ToLower(items[i].Title) < strings.ToLower(items[j].Title) })

		return Page{}, ErrUnsupported
	}
```

```go
package auth

import (
	"crypto/rand"
	"crypto/sha256"
	"encoding/base64"
)

func NewVerifier() (string, error) {
	b := make([]byte, 48)
	if _, err := rand.Read(b); err != nil {
		return "", err
	}
	return base64.RawURLEncoding.EncodeToString(b), nil
}

func Challenge(verifier string) string {
	sum := sha256.Sum256([]byte(verifier))
	return base64.RawURLEncoding.EncodeToString(sum[:])
}
```

```go
	codeCh := make(chan string, 1)
	errCh := make(chan error, 1)
	srv := &http.Server{Handler: http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if r.URL.Path != "/callback" {
			http.NotFound(w, r)
			return
		}
		q := r.URL.Query()
		if q.Get("state") != state {
			http.Error(w, "state invalide", 400)
			errCh <- errors.New("state OAuth invalide")
			return
		}
		if e := q.Get("error"); e != "" {
			fmt.Fprint(w, "Connexion annulée. Tu peux fermer cet onglet.")
			errCh <- fmt.Errorf("Spotify : %s", e)
			return
		}
		fmt.Fprint(w, "Connecté à Vinyl. Tu peux fermer cet onglet.")
		codeCh <- q.Get("code")
	})}
	go srv.Serve(ln)
	defer srv.Close()

	q := url.Values{
		"client_id": {clientID}, "response_type": {"code"}, "redirect_uri": {RedirectURI},
		"code_challenge_method": {"S256"}, "code_challenge": {Challenge(verifier)},
		"state": {state}, "scope": {scopes},
	}
	if err := a.OpenBrowser(a.AuthURL + "?" + q.Encode()); err != nil {
		return err
	}
	var code string
	select {
	case code = <-codeCh:
	case err := <-errCh:
		return err
	case <-ctx.Done():
		return ctx.Err()
	}
	tok, err := a.exchange(ctx, url.Values{
		"grant_type": {"authorization_code"}, "code": {code}, "redirect_uri": {RedirectURI},
		"client_id": {clientID}, "code_verifier": {verifier},
	}, "")
	if err != nil {
		return err
	}
	return a.Store.Save(tok)
}

func (a *SpotifyAuth) exchange(ctx context.Context, form url.Values, oldRefresh string) (Token, error) {
	req, err := http.NewRequestWithContext(ctx, "POST", a.TokenURL, strings.NewReader(form.Encode()))
	if err != nil {
		return Token{}, err
	}
	req.Header.Set("Content-Type", "application/x-www-form-urlencoded")
	resp, err := a.HTTP.Do(req)
	if err != nil {
		return Token{}, err
	}
	defer resp.Body.Close()
	if resp.StatusCode != 200 {
		return Token{}, fmt.Errorf("spotify token: HTTP %d", resp.StatusCode)
	}
	var body struct {
		AccessToken  string `json:"access_token"`
		RefreshToken string `json:"refresh_token"`
		ExpiresIn    int    `json:"expires_in"`
	}
	if err := json.NewDecoder(resp.Body).Decode(&body); err != nil {
		return Token{}, err
	}
	if body.RefreshToken == "" {
		body.RefreshToken = oldRefresh
	}
	return Token{AccessToken: body.AccessToken, RefreshToken: body.RefreshToken,
		Expiry: a.Now().Add(time.Duration(body.ExpiresIn)*time.Second - 30*time.Second)}, nil
}

func (a *SpotifyAuth) AccessToken(ctx context.Context) (string, error) {
	a.mu.Lock()
	defer a.mu.Unlock()
	tok, err := a.Store.Load()
	if err != nil {
		return "", ErrNotLoggedIn
	}
	if a.Now().Before(tok.Expiry) {
		return tok.AccessToken, nil
	}
	fresh, err := a.exchange(ctx, url.Values{
		"grant_type": {"refresh_token"}, "refresh_token": {tok.RefreshToken}, "client_id": {a.ClientID()},
	}, tok.RefreshToken)
	if err != nil {
		var netErr net.Error
		if errors.As(err, &netErr) {
			return "", err // réseau : on garde le jeton
		}
		a.Store.Delete()
		return "", ErrNotLoggedIn
	}
	if err := a.Store.Save(fresh); err != nil {
		return "", err
	}
	return fresh.AccessToken, nil
}
```

```go
package catalog

import (
	"context"
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"strconv"
	"strings"
	"time"

type SpotifyWeb struct {
	BaseURL string
	HTTP    *http.Client
	Token   func(context.Context) (string, error)
}

func NewSpotifyWeb(token func(context.Context) (string, error)) *SpotifyWeb {
	return &SpotifyWeb{BaseURL: "https://api.spotify.com/v1", HTTP: &http.Client{Timeout: 10 * time.Second}, Token: token}
}

type spImage struct {
	URL string `json:"url"`
}
type spArtist struct {
	ID   string `json:"id"`
	Name string `json:"name"`
}
type spAlbum struct {
	URI         string    `json:"uri"`
	Name        string    `json:"name"`
	ReleaseDate string    `json:"release_date"`
	Images      []spImage `json:"images"`
	Artists     []spArtist `json:"artists"`
}
type spTrack struct {
	URI     string     `json:"uri"`
	Name    string     `json:"name"`
	Artists []spArtist `json:"artists"`
	Album   spAlbum    `json:"album"`
}

func firstImage(imgs []spImage) string {
	if len(imgs) == 0 {
		return ""
	}
	return imgs[0].URL
}

func artistNames(as []spArtist) string {
	names := make([]string, len(as))
	for i, a := range as {
		names[i] = a.Name
	}
	return strings.Join(names, ", ")
}

func (c *SpotifyWeb) get(ctx context.Context, path string, q url.Values, out any) error {
	tok, err := c.Token(ctx)
	if err != nil {
		return err
	}
	u := c.BaseURL + path
	if len(q) > 0 {
		u += "?" + q.Encode()
	}
	req, err := http.NewRequestWithContext(ctx, "GET", u, nil)
	if err != nil {
		return err
	}
	req.Header.Set("Authorization", "Bearer "+tok)
	resp, err := c.HTTP.Do(req)
	if err != nil {
		return err
	}
	defer resp.Body.Close()
	switch {
	case resp.StatusCode == 429:
		return fmt.Errorf("Spotify limite les requêtes, réessaie dans %s s", resp.Header.Get("Retry-After"))
	case resp.StatusCode == 401:
		return fmt.Errorf("session Spotify expirée, reconnecte-toi")
	case resp.StatusCode != 200:
		return fmt.Errorf("spotify: HTTP %d", resp.StatusCode)
	}
	return json.NewDecoder(resp.Body).Decode(out)
}

func nextOffset(next *string, offset int) int {
	if next == nil || *next == "" {
		return -1
	}
	return offset + PageSize
}

func (c *SpotifyWeb) Library(ctx context.Context, kind string, offset int) (Page, error) {
	q := url.Values{"limit": {strconv.Itoa(PageSize)}, "offset": {strconv.Itoa(offset)}}
	var page Page
	switch kind {
	case "playlists":
		var body struct {
			Items []struct {
				URI    string    `json:"uri"`
				Name   string    `json:"name"`
				Images []spImage `json:"images"`
				Owner  struct {
					DisplayName string `json:"display_name"`
				} `json:"owner"`
			} `json:"items"`
			Next *string `json:"next"`
		}
		if err := c.get(ctx, "/me/playlists", q, &body); err != nil {
			return Page{}, err
		}
		for _, p := range body.Items {
			page.Items = append(page.Items, Item{ID: p.URI, Kind: "playlist", Title: p.Name, Subtitle: p.Owner.DisplayName, ArtworkURL: firstImage(p.Images)})
		}
		page.Next = nextOffset(body.Next, offset)
	case "albums":
		var body struct {
			Items []struct {
				Album spAlbum `json:"album"`
			} `json:"items"`
			Next *string `json:"next"`
		}
		if err := c.get(ctx, "/me/albums", q, &body); err != nil {
			return Page{}, err
		}
		for _, a := range body.Items {
			page.Items = append(page.Items, Item{ID: a.Album.URI, Kind: "album", Title: a.Album.Name, Subtitle: artistNames(a.Album.Artists), ArtworkURL: firstImage(a.Album.Images)})
		}
		page.Next = nextOffset(body.Next, offset)
	case "likes":
		var body struct {
			Items []struct {
				Track spTrack `json:"track"`
			} `json:"items"`
			Next *string `json:"next"`
		}
		if err := c.get(ctx, "/me/tracks", q, &body); err != nil {
			return Page{}, err
		}
		for _, t := range body.Items {
			page.Items = append(page.Items, Item{ID: t.Track.URI, Kind: "track", Title: t.Track.Name, Subtitle: artistNames(t.Track.Artists), ArtworkURL: firstImage(t.Track.Album.Images)})
		}
		page.Next = nextOffset(body.Next, offset)
	case "artists":
		// /me/following pagine par curseur ; on charge une seule page de 50 (suffisant pour un usage perso).
		if offset > 0 {
			return Page{Next: -1}, nil
		}
		var body struct {
			Artists struct {
				Items []struct {
					Name   string    `json:"name"`
					Images []spImage `json:"images"`
				} `json:"items"`
			} `json:"artists"`
		}
		if err := c.get(ctx, "/me/following", url.Values{"type": {"artist"}, "limit": {"50"}}, &body); err != nil {
			return Page{}, err
		}
		for _, a := range body.Artists.Items {
			page.Items = append(page.Items, Item{ID: a.Name, Kind: "artist", Title: a.Name, ArtworkURL: firstImage(a.Images)})
		}
		page.Next = -1
	default:
		return Page{}, ErrUnsupported
	}
	return page, nil
}

func (c *SpotifyWeb) artistID(ctx context.Context, name, trackID string) (string, error) {
	if id, ok := strings.CutPrefix(trackID, "spotify:track:"); ok {
		var t struct {
			Artists []spArtist `json:"artists"`
		}
		if err := c.get(ctx, "/tracks/"+id, nil, &t); err == nil && len(t.Artists) > 0 {
			return t.Artists[0].ID, nil
		}
	}
	var s struct {
		Artists struct {
			Items []spArtist `json:"items"`
		} `json:"artists"`
	}
	if err := c.get(ctx, "/search", url.Values{"type": {"artist"}, "q": {name}, "limit": {"1"}}, &s); err != nil {
		return "", err
	}
	if len(s.Artists.Items) == 0 {
		return "", fmt.Errorf("artiste introuvable : %s", name)
	}
	return s.Artists.Items[0].ID, nil
}

func (c *SpotifyWeb) Artist(ctx context.Context, name, trackID string) (ArtistPage, error) {
	id, err := c.artistID(ctx, name, trackID)
	if err != nil {
		return ArtistPage{}, err
	}
	var a struct {
		Name   string    `json:"name"`
		URI    string    `json:"uri"`
		Images []spImage `json:"images"`
	}
	if err := c.get(ctx, "/artists/"+id, nil, &a); err != nil {
		return ArtistPage{}, err
	}
	page := ArtistPage{Source: "spotify", Name: a.Name, ImageURL: firstImage(a.Images), URL: a.URI}

	var top struct {
		Tracks []spTrack `json:"tracks"`
	}
	if err := c.get(ctx, "/artists/"+id+"/top-tracks", url.Values{"market": {"FR"}}, &top); err != nil {
		return ArtistPage{}, err
	}
	for _, t := range top.Tracks {
		page.TopTracks = append(page.TopTracks, Item{ID: t.URI, Kind: "track", Title: t.Name, Subtitle: t.Album.Name, ArtworkURL: firstImage(t.Album.Images)})
	}
	var albums struct {
		Items []spAlbum `json:"items"`
	}
	if err := c.get(ctx, "/artists/"+id+"/albums", url.Values{"include_groups": {"album,single"}, "limit": {"50"}, "market": {"FR"}}, &albums); err != nil {
		return ArtistPage{}, err
	}
	for _, al := range albums.Items {
		year := al.ReleaseDate
		if len(year) >= 4 {
			year = year[:4]
		}
		page.Albums = append(page.Albums, Item{ID: al.URI, Kind: "album", Title: al.Name, Subtitle: year, ArtworkURL: firstImage(al.Images)})
	}
	return page, nil
}
```

```ts
export function escapeHtml(s: string): string {
  return s.replace(/[&<>"']/g, (c) => ({ "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#39;" })[c]!);
}

export function initials(title: string): string {
  const parts = title.trim().split(/\s+/).filter(Boolean);
  if (!parts.length) return "♪";
  return parts.slice(0, 2).map((p) => p[0]!.toUpperCase()).join("");
}

    <span class="truncate text-sm font-medium">${escapeHtml(item.title)}</span>
```

```ts
import { activeSource, api, type Item } from "../api";
import { go } from "../router";
import { escapeHtml, itemCard } from "./grid";

const TITLES: Record<string, string> = { playlists: "Playlists", albums: "Albums", likes: "Titres likés", artistes: "Artistes" };
const KIND: Record<string, string> = { playlists: "playlists", albums: "albums", likes: "likes", artistes: "artists" };

export function mount(el: HTMLElement, route: string): () => void {
  let alive = true;
  el.innerHTML = `<div class="p-8 pt-14">
    <h1 class="mb-6 text-2xl font-semibold">${TITLES[route]}</h1>
    <div id="grid" class="grid grid-cols-[repeat(auto-fill,minmax(150px,1fr))] gap-5"></div>
    <div id="status" class="mt-6 text-sm text-neutral-400"></div>
    <div id="sentinel" class="h-4"></div></div>`;
  const grid = el.querySelector<HTMLElement>("#grid")!;
  const status = el.querySelector<HTMLElement>("#status")!;
  const items = new Map<string, Item>();
  let source: "applemusic" | "spotify" = "applemusic";
  let next = 0;
  let loading = false;

  const showError = (e: unknown) => {
    const msg = String(e);
    if (msg.includes("non connecté") || msg.includes("reconnecte")) {
      status.innerHTML = `Connecte ton compte Spotify pour voir ta bibliothèque. <button id="go-settings" class="underline">Ouvrir les Réglages</button>`;
      status.querySelector("#go-settings")!.addEventListener("click", () => go("reglages"));
    } else if (msg.includes("non disponible")) {
      status.textContent = "Non disponible pour Apple Music.";
    } else if (msg.includes("non lancé")) {
      status.textContent = "Ouvre l'app Musique pour voir ta bibliothèque.";
    } else {
      status.innerHTML = `${escapeHtml(msg)} <button id="retry" class="underline">Réessayer</button>`;
      status.querySelector("#retry")!.addEventListener("click", load);
    }
  };

  async function load() {
    if (loading || next < 0 || !alive) return;
    loading = true;
    status.textContent = "Chargement…";
    try {
      const page = await api.Library(source, KIND[route], next);
      if (!alive) return;
      for (const it of page.items ?? []) {
        items.set(it.id, it);
        grid.insertAdjacentHTML("beforeend", itemCard(it));
        if (!it.artworkUrl && source === "applemusic" && it.kind !== "artist") lazyArtwork(it);
      }
      next = page.next;
      status.textContent = items.size === 0 ? "Rien ici pour l'instant." : "";
    } catch (e) {
      showError(e);
    } finally {
      loading = false;
    }
  }

  async function lazyArtwork(it: Item) {
    const url = await api.ItemArtwork(source, it.id).catch(() => "");
    const card = grid.querySelector<HTMLElement>(`[data-id="${CSS.escape(it.id)}"] [data-art]`);
    if (url && card) card.outerHTML = `<img src="${escapeHtml(url)}" class="aspect-square w-full rounded-md object-cover" alt="">`;
  }

  grid.addEventListener("click", async (e) => {
    const btn = (e.target as HTMLElement).closest<HTMLElement>("[data-id]");
    const it = btn && items.get(btn.dataset.id!);
    if (!it) return;
    if (it.kind === "artist") return go("artiste", it.title);
    try { await api.PlayItem(source, it.id); go("platine"); } catch (err) { showError(err); }
  });

  const observer = new IntersectionObserver((entries) => { if (entries.some((x) => x.isIntersecting)) load(); });
  activeSource().then((s) => {
    source = s;
    if (route === "likes" && s !== "spotify") { status.textContent = "Les titres likés sont disponibles avec Spotify."; return; }
    observer.observe(el.querySelector("#sentinel")!);
    load();
  });
  return () => { alive = false; observer.disconnect(); };
}
```

```ts
export const CARD_W = 1080;
export const CARD_H = 1350;

export function fitText(measure: (s: string) => number, text: string, maxWidth: number): string {
  if (measure(text) <= maxWidth) return text;
  let lo = 0, hi = text.length;
  while (lo < hi) {
    const mid = Math.ceil((lo + hi) / 2);
    if (measure(text.slice(0, mid) + "…") <= maxWidth) lo = mid; else hi = mid - 1;
  }
  return text.slice(0, lo).trimEnd() + "…";
}
```

```go
// SaveShareImage demande où enregistrer la carte de partage puis écrit le PNG. Renvoie "" si annulé.
func (s *VinylService) SaveShareImage(pngBase64, suggestedName string) (string, error) {
	data, err := base64.StdEncoding.DecodeString(pngBase64)
	if err != nil {
		return "", err
	}
	path, err := application.Get().Dialog.SaveFile().
		SetFilename(suggestedName).
		AddFilter("Image PNG", "*.png").
		CanCreateDirectories(true).
		PromptForSingleSelection()
	if err != nil || path == "" {
		return "", err
	}
	return path, os.WriteFile(path, data, 0o644)
}
```

```ts
import { api, type Settings } from "../api";
import { CARD_H, CARD_W, fitText } from "./layout";

export interface ShareInput { title: string; subtitle: string; artworkUrl: string; }

function loadImage(src: string): Promise<HTMLImageElement | null> {
  if (!src) return Promise.resolve(null);
  return new Promise((resolve) => {
    const img = new Image();
    img.crossOrigin = "anonymous";
    img.onload = () => resolve(img);
    img.onerror = () => resolve(null);
    img.src = src;
  });
}

export async function renderCard(input: ShareInput, s: Settings): Promise<HTMLCanvasElement> {
  const c = document.createElement("canvas");
  c.width = CARD_W; c.height = CARD_H;
  const g = c.getContext("2d")!;
  const bg = g.createRadialGradient(CARD_W / 2, 520, 50, CARD_W / 2, 520, 900);
  bg.addColorStop(0, s.accent + "66");
  bg.addColorStop(1, "#141414");
  g.fillStyle = bg;
  g.fillRect(0, 0, CARD_W, CARD_H);

  const cx = CARD_W / 2, cy = 560, r = 400;
  const art = await loadImage(input.artworkUrl);

  // Disque
  g.save();
  g.beginPath(); g.arc(cx, cy, r, 0, Math.PI * 2); g.clip();
  if (s.texture === "picture" && art) g.drawImage(art, cx - r, cy - r, r * 2, r * 2);
  else if (s.texture === "split") { g.fillStyle = s.discColors[0]; g.fillRect(cx - r, cy - r, r, r * 2); g.fillStyle = s.discColors[1]; g.fillRect(cx, cy - r, r, r * 2); }
  else if (s.texture === "yolk") { g.fillStyle = s.discColors[1]; g.fillRect(cx - r, cy - r, r * 2, r * 2); g.fillStyle = s.discColors[0]; g.beginPath(); g.arc(cx, cy, r * 0.42, 0, Math.PI * 2); g.fill(); }
  else if (s.texture === "solid") { g.fillStyle = s.discColors[0] + "cc"; g.fillRect(cx - r, cy - r, r * 2, r * 2); }
  else { g.fillStyle = "#111"; g.fillRect(cx - r, cy - r, r * 2, r * 2); }
  g.strokeStyle = "rgba(0,0,0,.25)"; g.lineWidth = 1;
  for (let rr = r * 0.4; rr < r; rr += 4) { g.beginPath(); g.arc(cx, cy, rr, 0, Math.PI * 2); g.stroke(); }
  g.restore();

  // Étiquette
  const lr = r * 0.36;
  g.save();
  g.beginPath(); g.arc(cx, cy, lr, 0, Math.PI * 2); g.clip();
  if (art) g.drawImage(art, cx - lr, cy - lr, lr * 2, lr * 2);
  else { g.fillStyle = s.accent; g.fillRect(cx - lr, cy - lr, lr * 2, lr * 2); }
  g.restore();
  g.fillStyle = "#111"; g.beginPath(); g.arc(cx, cy, 10, 0, Math.PI * 2); g.fill();

  // Textes
  g.textAlign = "center";
  g.fillStyle = "#fff";
  g.font = "700 64px -apple-system, sans-serif";
  g.fillText(fitText((t) => g.measureText(t).width, input.title, CARD_W - 160), cx, 1100);
  g.fillStyle = "#bbb";
  g.font = "400 40px -apple-system, sans-serif";
  g.fillText(fitText((t) => g.measureText(t).width, input.subtitle, CARD_W - 160), cx, 1170);
  return c;
}

export async function openShareCard(input: ShareInput): Promise<void> {
  const s = await api.GetSettings();
  const canvas = await renderCard(input, s);
  const overlay = document.createElement("div");
  overlay.className = "fixed inset-0 z-50 flex items-center justify-center bg-black/70";
  overlay.innerHTML = `<div class="flex flex-col items-center gap-4 rounded-xl bg-neutral-900 p-6">
      <img class="h-[60vh] rounded-lg" alt="Carte de partage">
      <p id="share-msg" class="text-sm text-neutral-400"></p>
      <div class="flex gap-3">
        <button id="copy" class="rounded px-4 py-1.5 text-neutral-900" style="background:var(--accent)">Copier</button>
        <button id="save" class="rounded border border-white/30 px-4 py-1.5">Enregistrer…</button>
        <button id="close" class="rounded px-4 py-1.5 text-neutral-400">Fermer</button>
      </div></div>`;
  document.body.appendChild(overlay);
  const msg = overlay.querySelector<HTMLElement>("#share-msg")!;
  let dataUrl = "";
  try { dataUrl = canvas.toDataURL("image/png"); }
  catch { msg.textContent = "La pochette ne peut pas être exportée (image protégée) : la carte sera générée sans elle."; }
  if (!dataUrl) dataUrl = (await renderCard({ ...input, artworkUrl: "" }, s)).toDataURL("image/png");
  overlay.querySelector("img")!.src = dataUrl;

  overlay.querySelector("#close")!.addEventListener("click", () => overlay.remove());
  overlay.addEventListener("click", (e) => { if (e.target === overlay) overlay.remove(); });
  overlay.querySelector("#copy")!.addEventListener("click", async () => {
    try {
      const blob = await (await fetch(dataUrl)).blob();
      await navigator.clipboard.write([new ClipboardItem({ "image/png": blob })]);
      msg.textContent = "Copiée dans le presse-papier.";
    } catch { msg.textContent = "Copie impossible ici, utilise « Enregistrer… »."; }
  });
  overlay.querySelector("#save")!.addEventListener("click", async () => {
    const name = `${input.title || "vinyl"}.png`.replace(/[\/:]/g, "-");
    const path = await api.SaveShareImage(dataUrl.split(",")[1]!, name);
    if (path) msg.textContent = `Enregistrée : ${path}`;
  });
}
```
